# 보안 단어장

결과에 이 단어가 나오면 괄호 안에 아래 뜻을 한 줄로 붙인다.

## 기본
- **API 키:** 서비스를 쓰는 이용권. 신용카드처럼 남이 쓰면 돈은 내가 낸다.
- **.env, 환경변수:** 비밀 키를 넣어 두는 금고. GitHub에 올리지 않는다.
- **.gitignore:** GitHub에 올리지 말 파일 목록.
- **프론트엔드:** 브라우저에서 보이는 화면. F12로 누구나 코드를 본다.
- **백엔드, 서버:** 사용자에게 안 보이는 주방. 비밀이 필요한 일은 여기서.
- **NEXT_PUBLIC_:** 이 이름이 붙은 값은 화면으로 나가는 공개 값.
- **HTTPS:** 주고받는 내용을 잠긴 봉투에 넣어 보내는 것. S는 Secure. Vercel이 자동으로 해 준다.

## 로그인과 권한
- **인증:** 너 누구야? 로그인.
- **인가:** 너 이거 해도 돼? 로그인한 사람이 할 수 있는 범위.
- **세션, 토큰:** 로그인 상태를 기억하는 표.
- **JWT:** 로그인했다는 디지털 출입증의 한 종류.
- **2단계 인증:** 비밀번호에 문자나 앱 확인을 하나 더.
- **무작위 대입(브루트포스):** 비밀번호를 기계가 수천 번 넣어 보는 공격.

## Supabase
- **RLS:** 표의 줄마다 거는 자물쇠. 끄면 공개 키만으로 표 전체가 보인다.
- **정책(Policy):** 자물쇠 규칙. 조회, 추가, 수정, 삭제마다 따로 정한다.
- **anon, publishable 키:** 공개 키. 화면에 있어도 되고 RLS를 따른다.
- **service_role 키:** 마스터 키. 모든 자물쇠를 무시하니 서버에만 둔다.
- **Storage 버킷:** 사진 같은 파일 보관함. 공개면 주소만 알면 누구나 본다.

## 공격 이름
- **XSS:** 게시글에 숨긴 코드가 남의 브라우저에서 실행되는 공격.
- **SQL 인젝션:** 입력창에 DB 명령어를 넣는 공격.
- **CSRF:** 내가 로그인한 상태를 몰래 이용해 다른 사이트가 요청을 보내게 하는 공격.
- **SSRF:** 내 서버를 시켜 내부의 다른 곳을 두드리게 하는 공격.
- **IDOR:** 주소의 번호만 바꿔서 남의 데이터를 보는 것.
- **프롬프트 인젝션:** 글이나 파일 속에 AI에게 몰래 지시를 숨기는 공격.
- **공급망 공격:** 내가 가져다 쓴 패키지, 스킬, 레포에 나쁜 코드가 숨어 있는 것.

## 운영
- **호출 횟수 제한(Rate limit):** 짧은 시간에 너무 많이 못 부르게 막는 장치.
- **해시:** 되돌릴 수 없게 갈아서 저장하는 방식. 비밀번호는 이렇게 저장한다.
- **마스킹:** 010-****-1234처럼 일부를 가리는 것.
- **위탁:** 개인정보를 AI나 클라우드 같은 남의 서비스에 맡기는 것. 처리방침에 적는다.
